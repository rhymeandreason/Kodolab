Layout tokens

A page sets --page-max and almost nothing else. The gutter is a token rather than a padding, so a full-bleed child undoes it with one negative margin instead of guessing the clamp.

Surfaces and text

semantic

Pages name these, not the ramp underneath. --surface-stage is the ground a molecule is drawn on: a step warmer than the paper, because the canvas is alpha:true and this is what shows through it.

Atoms

Generated from palette.js at load by tokens-from-palette.js, so a caption and the sphere it names cannot drift. Oxygen used to be #e6362f in CSS and #d6362e in the renderer.

Bonds

—

A bond's colour is a lesson, not an element.

Organelles

One organelle, one colour, wherever it is drawn. cell/animalcell.js chose these against this paper and they are the house numbers now, so a membrane lesson set inside a mitochondrion tints its bilayer with the same orange the cut cell paints it. The bare name is the outside face; a -head and -tail are the bilayer tint, and only the organelles that HAVE a membrane carry them.

Lesson domains

domain

A colour a lesson reads, on two conditions: nothing else already publishes it, and more than one page reads it. Four tokens here restated a generated one (the ion-dipole amber, the protein H-bond, phosphorus, carbon) — the oxygen bug above with new names — and the pages now say --bond-iondipole, --bond-hbond, --atom-P, --atom-C. Three more had a single caller and went back to it: a system that carries a one-page colour is a place to lose it, not a place to share it.

Type

two sans, one serif

Split by job. --font-display is the geometric one: a wordmark, a masthead, a micro-cap, a numeral a page reads out. --font-ui is system-ui and is what everything is actually read in, because a display face sets a paragraph badly and its 600 at 13px is a black bar. --font-shout and --font-aside are the sketchbook's two hands and now resolve into this pair, which is what carried the marker headings and the margin scrawl across without touching a page.

Families

Micro-caps — the only heading device outside prose

Same face, tracking, weight and colour. The size is the entire hierarchy, so a page cannot invent a third treatment by picking its own tracking.

Buttons

six shapes

.cta and .pill are not the same button. A pill is an instrument standing on the model's paper, so it is a solid body with a side and a shadow. A cta is a flat capsule set in a document, where a raised key would read as a sticker. Which one a control is depends on what it is lying on, not on how important it is.

Tab through them: every shape takes the same focus ring. Each row prints its own computed padding, size and height, so a stale stylesheet cannot hide here.
